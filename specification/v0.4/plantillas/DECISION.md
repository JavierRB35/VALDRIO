# Decisión metodológica o técnica

ID y título. Estado Propuesta / Aceptada / Sustituida. Fecha y persona que acepta.

## Problema concreto

Qué pregunta económica o restricción técnica necesita resolver la decisión.

## Entrada y alternativas

Datos de un ejemplo, variantes y resultado de cada una. Para decisión técnica, conservar la misma semántica económica cuando sea posible.

## Decisión

Regla escogida, ámbito, unidades y límites. Identificar si afecta únicamente demostración o uso definitivo.

## Consecuencias

Contratos, casos, modelo, algoritmo, esquema y tareas afectados. Versiones nuevas necesarias. Resultados históricos que deben conservarse.

## Aceptación y verificación

Ejemplo aceptado, evidencia y referencias. Criterio para revisar esta decisión.
