# T10 — Solver recíproco y prueba de viabilidad

**Estado:** candidato técnico en rama `feature/t10-solver-reciproco-viabilidad`, sin cierre de aceptación. Fuente normativa: [T10 v0.4](../../specification/v0.4/tareas/T10.md), CM06 y A05; dependencias T02 y T08. T09 está incorporada en main, pero su aceptación nativa histórica no se deduce de esta entrega.

## Implementado

- `ReciprocalGraphBuilder.FromPublishedSecondaryKeys` transforma claves secundarias **publicadas** de T08 (por grupo de enrutamiento) en Q, B. Los pesos de porcentaje se dividen entre 100, DriverUnits/EqualShares por su suma; la última ruta ordenada por ID recibe el residuo decimal. No inventa destinos ni ignora reglas inexistentes.
- `ReciprocalFactorization.Prepare` valida IDs, cobertura exacta, autorreparto y alcanzabilidad incluso para costes cero; calcula M=I-Qᵀ y LU decimal con pivoteo parcial y desempates deterministas. Mantiene factorización reutilizable para múltiples orígenes, calcula factores terminales, pivotes y amplificación.
- `ReciprocalFactorization.Solve` acepta costes firmados y términos independientes cero; calcula bruto auxiliar, destino final y residuos absoluto/relativo; emite diagnósticos estructurados y avisos, sin uso de double ni resultados monetarios posteados.
- `Valdrio.Runner` genera informes JSON de viabilidad, tanto desde matrices sintéticas como desde un recibo congelado real de T08. El segundo modo revisa **rutas** con RHS cero, nunca inventa costes ni publica ejecución T11.
- Mensajes ES/EN, tests con corpus C09–C14/C32, cancelación, 100 auxiliares, invariancia cultural, orden estable e integración con reglas secundarias T08.

## Reproducción

```powershell
dotnet run --project src/Valdrio.Runner -- --reciprocal-input samples/t10-reciprocal-c09.json
dotnet run --project src/Valdrio.Runner -- --reciprocal-study-snapshot .\receipt-t08.json all
```

Salida 0 = viable; 4 = bloqueo metodológico; 3 = entrada incompatible. Contrato propuesto `PNUM-1-proposed`. Las rutas de grupos diferentes se analizan por separado.
