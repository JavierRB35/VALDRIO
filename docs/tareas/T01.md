# T01 - Repositorio, SDK y CI Windows

Estado: **EN EJECUCIÓN**

## Objetivo respaldado por la especificación

- Repositorio/solución modular.
- SDK y paquetes fijados tras comprobar versiones vigentes.
- CI Windows.
- Aplicación WPF mínima.
- Artefacto de desarrollo Windows.
- Evidencia de que el ejecutable arranca y abre un archivo de ejemplo.

La especificación también aclara que T01A sigue a T01 antes de pantallas funcionales.

## Alcance implementado en esta rama

- Solución `Valdrio.slnx` con los módulos previstos.
- `global.json` con .NET SDK 10.0.401.
- Versiones NuGet centralizadas.
- Shell WPF mínima sin cálculo económico.
- Fixture de desarrollo no económico que la shell carga al arrancar.
- Tests de límites básicos de dependencias para Domain y Calculation.
- GitHub Actions sobre `windows-latest`: restore, build, test, publish, smoke de arranque y artefacto win-x64.

## Qué NO implementa T01

- No hay fórmula de costes.
- No hay DbContext, migraciones ni formato de archivo productivo.
- No hay importación contable.
- No hay recursos bilingües ni cambio de cultura: eso corresponde a T01A.
- No hay revisión visual humana de la ventana todavía.

## Criterio para marcar T01 completada

1. CI Windows verde.
2. Build Release de `Valdrio.slnx`.
3. Pruebas ejecutadas y verdes.
4. `dotnet publish` genera `valdrio-t01-win-x64`.
5. El proceso WPF arranca en Windows con el fixture y sigue vivo durante el smoke.
6. Se registra el workflow/run y el commit exactos en la evidencia.

Una prueba de proceso vivo demuestra arranque automatizado; no se confundirá con revisión visual de interfaz.
